# 3D 흠집 핀 위치 보정 (부스 카메라 FRAME)

공개 기기 상세(`/devices/:id`)와 부스 빠른 검사 흠집 모양은 부스 원본 사진 좌표(px)를 노트북 면 좌표로 옮겨 3D에 핀을 꽂는다.
옮기는 규칙은 `src/shared/laptop3d/faces.ts`의 `FRAME`(위 카메라 CAM1·CAM2)과 `SIDE_FRAME`(옆면 카메라) 값 하나다.
**부스를 다시 만들거나 카메라 높이·각도를 바꾸면 이 값만 다시 잰다.**

## 지금 값 (11/9)

- 11/5~11/6 부스 사진 MB02·MB08(바닥)·MB07·MB13(윗면) L1, CAM1·CAM2 각 4장에서 잰 네 모서리 평균.
- 두 카메라 모두 면 **전체**를 찍는다(앞 반·뒤 반으로 나뉘지 않는다). CAM1은 약 8° 돌아가 있고, CAM2는 아래쪽이 좁은 사다리꼴이라 네 점 호모그래피로 옮긴다.
- 윗면 사진은 위쪽이 경첩(사과 로고가 거꾸로 보임). 바닥은 앞 모서리를 들어 뒤로 넘겨 찍으므로 사진 위쪽이 앞 모서리이고, 표준 면 좌표와 180° 돌아 있다(코드가 돌린다).
- 검증: 기기별 모서리로 옮기면 같은 흠집의 CAM1·CAM2 위치 차이 1.6~4mm. 평균 모서리로는 노트북 놓는 자리 차이 때문에 6~18mm 어긋난다(예전 반쪽 규칙은 40~90mm, 바닥은 좌우도 뒤집혔음).
- 옆면·화면(옆면 카메라)과 키보드는 아직 실제 사진으로 재지 않았다. 키보드는 바닥 자리가 같아 위 카메라 값을 같이 쓴다.

## 다시 재는 법 (10분)

1. 부스에서 노트북을 표시한 자리에 놓고 윗면을 CAM1·CAM2로 한 장씩 찍는다(빠른 검사 사진 그대로 써도 된다). 가능하면 2~3대.
2. `python scripts/pin-grid.py <사진들>` → 5% 눈금이 그려진 `.grid.png`가 생긴다.
3. 사진마다 노트북 면의 **왼쪽 위·오른쪽 위·오른쪽 아래·왼쪽 아래** 모서리를 사진 비율(0~1)로 읽는다(사진에 보이는 그대로, 둥근 모서리는 두 변을 연장한 점).
4. 카메라별로 평균을 내 `FRAME.CAM1`·`FRAME.CAM2`에 넣는다. 옆면 카메라도 같은 방법으로 옆면 사진 한 장에서 `SIDE_FRAME`을 잰다.
5. `npm test`에서 "같은 흠집은 CAM1·CAM2 어느 사진으로 옮겨도 2cm 안에서 만난다" 테스트의 흠집 위치도 새 부스 사진 값으로 바꾼다.
